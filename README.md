# Đọc Truyện Trung

App đọc truyện tranh Trung Quốc (Tencent Comics) bằng âm Hán Việt — © Võ Thái Anh.

Mở: https://thaianh111.github.io/hoc-tieng-trung/

- Chụp màn hình truyện → khoanh khung lời thoại → app đọc chữ, hiện âm Hán Việt, nghĩa tiếng Việt, pinyin, đọc to.
- Sổ chữ + ôn nhanh kiểu lật thẻ.
- Chữ hay gặp: tu tiên, xuyên không, đô thị, hậu cung.

Dữ liệu: CVDICT (CC BY-SA 4.0, Phong Phan), hanviet-pinyin-words (MIT), Tesseract.js (Apache-2.0), jieba (MIT, tần suất từ).
